## What To Compare

- First screen: purpose, audience, and first useful command.
- Quickstart: how quickly a user reaches a working example.
- Expected output: whether the README shows what success looks like.
- CLI shape: how commands, flags, and configuration are summarized.
- Status boundaries: how alpha, experimental, or unsupported behavior is named.
- Routing: what stays in the README versus what moves to docs.
- Contribution/support links: how maintainers direct issue reports and community
  usage.
