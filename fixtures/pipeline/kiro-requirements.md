# Checkout feature

**User Story:** As a shopper, I want to pay, so that I can complete my order.

#### Acceptance Criteria

1. WHEN a payment webhook arrives THE SYSTEM SHALL verify the signature.
2. IF the signature is invalid THEN THE SYSTEM SHALL reject the webhook.
